botbench playground

Everything here calls botbench.js straight from your browser. Nothing is sent to any server of mine. Free APIs are contacted directly by your browser, so a few may refuse because of CORS (see the proxy box at the bottom).

Try an API



Pick a function and press Run.

Send through a webhook


Paste a webhook URL from Channel settings, Integrations. It stays in this page. Anyone with the URL can post to that channel, so don't share it.








CORS proxy (optional)


If an API works in Node but fails here with a network error, it blocks browsers. Give the playground a proxy that takes ?url= and calls botbench.config({ proxy }).
