# Free APIs for bots (115)

Key **None** means you can call it without signing up. Free APIs change or shut down: open the URL before you build on it, and read the provider's terms.

## AI

| API | Key | What it does |
|---|---|---|
| [Claude API](https://docs.claude.com) | Paid | Add an AI assistant command. Each call costs money, so add cooldowns. |

| [Google Gemini API](https://ai.google.dev) | Free tier | Chat models. Has a free tier with limits. |
| [Hugging Face](https://huggingface.co/docs) | Free tier | Hosted open models. |
